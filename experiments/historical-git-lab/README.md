# Historical Git timestamp lab

This directory and every commit that changes it are a synthetic experiment. They do not describe work performed on these dates. The application source, tests, and existing history are kept intact.

Each `LAB (synthetic):` commit appends one row to `activity.csv`. `GIT_AUTHOR_DATE` is set to the lab date; `GIT_COMMITTER_DATE` is set later on the same date to make the distinction inspectable while keeping both timestamps in the chosen historical year.

This lab is local until separately pushed. GitHub contribution display depends on account email attribution and branch/repository eligibility; this history is explicitly synthetic.

Coverage: 2015 through 2026-11-02, with intentionally irregular active months and gaps.
